### Gift-Card.Mline

Plataforma full-stack de gestión de gift cards. Empezó como mi proyecto de tesis y terminó **en producción**, siendo usada por el equipo de una empresa real.

Hice todo de cabo a rabo: diseño de BD, integración de pagos con WebPay/Transbank, panel admin, generación de códigos y gestión de campañas.

`Next.js 15` · `React 18` · `MariaDB` · `Cloudinary`
